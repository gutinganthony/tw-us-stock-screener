# 台美股三策略篩選器

這是一個可在本機或 Render 雲端執行的互動式研究工具，將三套口語選股方法轉成可調參數與逐項檢查結果：

1. 主力拉盤前期／洗盤型態
2. 隔日沖（一夜持股法）
3. 大漲前四特徵

## 開啟方式

macOS 可直接雙擊 `啟動篩選器.command`。啟動後會打開瀏覽器；關閉終端機視窗即可停止。

若系統阻擋第一次開啟，可在檔案上按右鍵，選擇「打開」。也可以在此資料夾執行：

```bash
python3 server.py --open
```

預設網址是 <http://127.0.0.1:8765/>。

## GitHub＋Render 部署

專案已包含 `render.yaml`、`requirements.txt`、`.python-version` 與 `Procfile`。Render 可直接連接此 GitHub 儲存庫並建立 Python Web Service：

- Build command：`pip install --no-cache-dir -r requirements.txt`
- Start command：`python server.py --host 0.0.0.0`
- Health check：`/api/health`
- 連接主要分支後，每次 push 可自動重新部署。

公開版內建保護：相同條件快取 5 分鐘、最多同時處理 2 個昂貴查詢、單一來源每 10 分鐘最多 20 次未快取篩選，以及基本瀏覽器安全標頭。這些值可用 `render.yaml` 內的環境變數調整。

## 資料來源與運作方式

- 「廣域候選」先用 TradingView Scanner 取得市場快照、流通股本與候選清單，再以 Yahoo Finance／yfinance 下載 6 個月日線。
- 洗盤與四特徵策略會依當日成交量取廣域候選，預設 200 檔、最高可調到 1,000 檔；隔日沖則先在廣域市場套用漲幅、量比、市值與換手條件，再下載少量候選的詳細資料。
- 隔日沖策略可額外下載最近 5 個交易日的 5 分鐘線，計算 VWAP、站上 VWAP 的時間比例及相對大盤強弱。
- 「自訂清單」可貼入代碼；台股純數字代碼會自動加上 `.TW`。上櫃股票請明確輸入 `.TWO`。
- 盤中執行時，當日漲幅、量能與換手率仍會變動，介面會提示「盤中」。

## 重要定義

- 台股「20 日內漲停」預設以單日上漲至少 9.5% 近似，以容納跳動單位與資料差異。
- 美股沒有台股式每日漲停；同一條件改為「20 日內單日大漲」，預設門檻 10%，可自行調整。
- 廣域候選模式的換手率優先使用流通股本；自訂清單若只有總股本，會清楚標示為代理值。
- 洗盤觀察期預設為 63 個交易日，對應約三個月，可在進階條件調整。
- 「主力持股 30–50%」與真實「大單托底」需要籌碼或 Level 2 委託簿資料。本工具不會用 OHLCV 型態冒充這兩項證據，因此輸出採「代理訊號／疑似型態」用語。

## 測試結果

建置前已用 20 檔台股與 20 檔美股做可行性測試：

- 40/40 檔成功取得 6 個月日線。
- 8/8 檔成功取得股本並計算換手率與市值代理值。
- 台積電、聯發科、Apple、NVIDIA 均成功取得 5 分鐘線，並完成 VWAP 與相對大盤計算。
- 40 檔完整批次約 10 秒完成；廣域候選的時間會依候選數與網路狀況增加。
- 正式版另完成 6 組跨市場回歸測試：三套策略都分別在台股與美股實際執行成功。

## 限制

- TradingView Scanner 與 Yahoo Finance 都是第三方資料介面，可能限流、延遲或調整格式；這不是交易所等級即時報價服務。
- 免費盤中資料可能延遲，且 5 分鐘線不等於逐筆成交或委託簿。
- 訊號只用於研究與縮小候選範圍，不構成投資建議，也不保證隔日報酬。
